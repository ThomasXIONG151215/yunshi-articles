# VFED Video Design Spec

## Style: Swiss Pulse (Academic / Technical)

**Mood:** Clinical, precise, data-driven
**Best for:** Academic presentations, technical frameworks, metrics-heavy content

## Colors
- Background: `#faf9f5` (warm off-white)
- Primary text: `#141413` (near-black)
- Accent: `#d97757` (warm orange - matches brand)
- Data blue: `#4285f4` (for charts/stats)
- Grid/lines: `#e8e6dc`

## Typography
- Headlines: Inter Bold, 80-120px
- Body: Inter Regular, 24-32px
- Data labels: Inter Medium, 16-20px
- All caps for section headers

## Motion Philosophy
- Fast, precise entrances (power3.out)
- Counter animations for numbers
- Grid-based layout
- Minimal decoration
- Crossfade transitions between scenes
